## [Current Optimization Goals]
1. VDB 유사도 검색 시 '보간법'과 '신규 단가'를 가르는 최적의 임계값(Threshold) 찾기.
2. LangGraph 노드 병렬 처리 시 API Rate Limit(429 에러)이 걸리지 않는 최적의 Concurrency 찾기.

## [Preferences & Working Hints]
- 대조군(Baseline) 데이터가 주어지지 않으면, 가장 최근 기록된 성공적 실험을 대조군으로 삼을 것.
- 오류 로그에 Rate Limit이나 Timeout이 보이면 가장 심각한 이슈로 최상단 하이라이트.
- 표를 그릴 때 증감률 기호(🔺, 🔻) 사용.
- 사용자가 로그나 Grafana 지표를 파일 대신 텍스트로 직접 붙여넣으므로, 탭 구분 텍스트(TSV)나 터미널 표준 출력 로그 형식도 유연하게 파싱하여 분석할 것.
- 파일 리더(file_reader) 호출을 시도하지 말 것 (사내망 보안 정책상 파일 업로드 차단).
